Copilot Prompt Helper | Copilot 提示助手

Tips for Better Copilot Prompts | 提示優化技巧:
  • Be specific about the programming language | 明確指定程式語言
  • Include context about the project | 包含專案背景資訊
  • Specify input/output requirements | 明確輸入/輸出要求
  • Mention any frameworks or libraries | 提及框架或函式庫
  • Include error handling preferences | 包含錯誤處理偏好

Copilot 提示語清單 (手機改 Code 專用) | Mobile Code Editing Prompts

1. 改文字 | Change Text

In [index.html], please change the text inside the [header section] from "Welcome" to "Hello Hudson".

👉 用途：改標題、改段落字、button 上面文字。

💡 提示：用「header / footer / nav bar / button / paragraph」去描述位置。

2. 改顏色 / 風格 | Change Colors/Styles

In [style.css] or [script.js], update the [button section] background color to red.

👉 用途：改字體顏色、button 色、背景色。

💡 提示：如果唔知係 CSS 定 JS，就直接講「style or script」。

3. 加新元素 | Add New Elements

In the [nav bar section] of index.html, please add a new menu item called "Contact Us" that links to contact.html.

👉 用途：加新選單、加新按鈕、加一段內容。

4. 改功能 | Change Functionality

In [script.js], please update the button click function so that when clicked, it shows an alert message: "Hello Hudson!"

👉 用途：控制按鈕動作、彈出訊息、互動效果。

5. 圖片 / 圖示 | Images/Icons

In [index.html], replace the image in the [hero section] with "myphoto.jpg" from the assets folder.

👉 用途：換 banner 圖、換 logo、加 icon。

6. 定位幫助 | Location Help

I want to change the text in the top header of the webpage (screenshot attached). Which file should I edit, and can you show me the code I need to update?

👉 用途：當你唔肯定係 HTML、CSS 定 JS，就交俾 Copilot 幫你揾。
